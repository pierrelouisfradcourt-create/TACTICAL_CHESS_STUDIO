## Promotion / fusion / sorts (règles “probables finales” dans ces sources)
Promotion :
- Promotion “classique” au bout du plateau.
- Promotion spéciale possible via “roi tacticien”.
- Limite suggérée : pas plus d’une promotion par niveau pour les effets spéciaux.

Fusion :
- Cadrage progressif : seulement certains types.
- Certaines fusions “coûtent un sort”.
- Fusion roi/reine seulement avant partie ; roque interdit.

Sorts :
- Tous les sorts draftés accessibles ; limite évoquée : 1 sort par tour.
- Existence d’un contresort (wording et restrictions encore flous ici).

## Traduction autobattler (points exploitables)
- Sideboard = “shop” / réserve d’options (évolutions, techs, sorts de tempo) entre rounds.
- 1 sort par tour/round = levier de skill sans casser l’autobattle (cap clair).
- Promotions/fusions = spike de puissance maîtrisé, idéalement limité par rareté/budget + garde-fous.

# RNG DU JEU — VERSION STUDIO

## Principe central

Chaque carte est générée avec un **budget de puissance**.

La carte dépense ce budget dans :

```
stats
forme d’attaque
effets
portée
capacités
```

Le but est que **toutes les cartes restent équilibrées même si elles sont générées aléatoirement**.

---

# 5. Modificateurs RNG

Certains effets modifient les stats automatiquement.

Exemples :

### brûlure

```
attaque -1
coût réduit de 1
```

### poison

```
attaque -1
coût réduit de 1
```

### faiblesse

```
attaque -1
coût réduit de 1
```

---

# 6. Taxe de portée

Plus une attaque est longue, plus elle coûte.

```
portée 1 = 0
portée 2 = +1
portée 3 = +2
portée 4+ = +3
```

---

# 7. Taxe multi-cibles

Attaquer plusieurs unités augmente fortement le coût.

| type     | coût |
| -------- | ---- |
| 1 cible  | 0    |
| 2 cibles | 1    |
| ligne    | 2    |
| zone     | 3    |

---

# 8. Contraintes anti-abus

Certaines combinaisons sont interdites :

❌ gel + ligne complète
❌ charme + zone
❌ stun + portée >3
❌ double debuff majeur

Ces règles empêchent les cartes cassées.

---

# 9. Variance contrôlée

La RNG doit produire :

```
20% cartes faibles
60% cartes moyennes
20% cartes fortes
```

Cela reproduit la dynamique des TCG.

---

# 10. Génération d’une carte (exemple)

```

tirage RNG :

```
PV 6 (2)
ATK 2 (1)

portée 2 (1)
```

6 / 6
```

Carte valide.

# 11. Génération d’un set

Chaque faction contient :

```
3 héros (combat / tacticien / mage)

pour chaque héros :

1 pion spécial
1 cavalier
1 fou
1 tour
1 reine
1 sort
```

Total :

```
≈ 18 cartes par faction
```

# 15. Sécurité RNG (très important)

Chaque carte passe par **3 filtres** :

```
filtre puissance
filtre abus
filtre identité faction
```

Si un filtre échoue → la carte est régénérée.

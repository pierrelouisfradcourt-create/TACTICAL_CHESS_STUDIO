# 12. Event Queue

```
eventQueue {
    pendingEvents[]
}
```

Traitement :

```
while eventQueue not empty
    event = popHighestPriority()
    resolve(event)
    enqueue resulting events
```

---

# 13. Action Resolution Pipeline

Pipeline complet :

```
1 validateAction
2 buildPath
3 generateTraversalEvents
4 resolveTraversalCounterattacks
5 arrival
6 resolveAttack
7 retaliation
8 triggerProcessing
9 markDeaths
10 cleanupDead
11 promotionCheck
12 summonCleanup
13 passiveRefresh
14 brawlResolution
15 cleanupDead
16 pressureRecompute
17 victoryCheck
```

---

# 14. Traversal Resolution

Pour chaque case du chemin :

```
for tile in path:
    checkControllers(tile)
    generateCounterattacks
    resolveDamage
    if actorDead:
        stopTraversal
```

---

# 15. Counterattack Logic

```
counterattackDamage =
controller.ATK
+ supportBonus
- actor.ARM
```

---

# 16. BRAWL Resolution

BRAWL utilise un snapshot.

```
snapshot = captureBoard()

for pair in adjacentEnemies:
    applyBrawlDamage
```

Damage :

```
brawlDamage =
ATK
+ support
+ terrainBonus
- armor
```

---

# 17. Death Processing

Mort est traitée en trois phases.

```
1 markDead
2 trigger onDeath
3 cleanupRemoval
```

---

# 18. Pressure Recompute

```
pressure =
directThreat
+ supportThreat
+ escapeDenial
+ statusPressure
+ brawlPressure
```

# Simulation Framework

Permet de tester et équilibrer le jeu automatiquement.

---

# 1. Simulation Engine

```
SimulationEngine {
    runGame()
    runBatchSimulation()
    collectMetrics()
    updateBalance()
}
```

---

# 2. Game Simulation

```
runGame(seed):
    initializeGame(seed)
    while not victory:
        action = AI.selectAction()
        applyAction(action)
```

---

# 3. Batch Simulation

```
runBatchSimulation(N):
    for i in 1..N:
        runGame(seed+i)
        collectMetrics
```

---

# 4. Metrics Collection

```
metrics {
    averageTurns
    pressureVictoryRate
    kingKillRate
    pieceSurvival
    archetypeWinrate
    rareDependency
}
```

---

# 5. Auto Balance

Auto balance ajuste les cartes.

```
if winrate(archetype) > 60%:
    nerfCards(archetype)
```

```
if winrate(archetype) < 40%:
    buffCards(archetype)
```

---

# 6. Card Adjustment

```
nerfCards():
    reduceStats
    increaseCost
    reduceRange
    addRestrictions
```

```
buffCards():
    increaseStats
    addMinorEffect
    reduceCooldown
```

---

# 7. Simulation Targets

Objectifs :

```
pressureVictoryRate = 40-60%
averageGameLength = 18-30 turns
rareDependency < 20%
comebackRate = 25-35%
```

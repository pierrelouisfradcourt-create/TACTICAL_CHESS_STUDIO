# SECTION 10 - — DENSITÉ DES EFFETS DANS UNE PARTIE
10.1 Sorts joués
limite : 1 sort par tour [Explicite]

en partie moyenne :

3 à 6 sorts joués [Hypothèse plausible]

plus si roi mage autorise un pic ponctuel

10.2 Altérations présentes
Dans une partie moyenne :

4 à 10 applications d’altérations [Hypothèse plausible]

dont 1 à 3 altérations fortes maximum si le set est sain

10.3 Promotions
0 à 2 promotions dans une partie standard [Reconstruction forte]

plus dans certains matchups orientés progression

10.4 Invocations
cap d’invocation permanente faible

en partie moyenne :

0 à 3 invocations effectives [Hypothèse plausible]

hors couvée

10.5 Fusions
0 à 2 fusions dans une partie moyenne [Hypothèse plausible]

la fusion royale couvée étant une exception très structurante

# SECTION 2 - — TIMINGS ET ORDRE DE RÉSOLUTION
Il n’existe pas un seul ordre entièrement verrouillé, mais plusieurs versions convergent.

2.1 Version ancienne / intuitive
Une structure plus simple était implicite :

déplacement

attaque / prise

application des effets

fin de tour

Cette version a été jugée trop faible pour rendre compte :

des opportunités

de la Brawl

des altérations persistantes

du terrain.

2.2 Version intermédiaire
Une version plus riche a émergé :

début de tour

effets persistants

déplacement

attaques d’opportunité

attaque principale

application des dégâts

application des altérations

morts

fin de tour

Cette version a servi de base à la réflexion.

2.3 Version la plus cohérente avec le design final
Début de tour
vérifier les effets persistants :

brûlure

poison

régénération

terrain actif

vérifier les déclenchements de début de tour :

soins de cavalier protecteur

auras éventuelles

états qui expirent

Action du tour
choisir éventuellement 1 sort

résoudre le sort

choisir 1 pièce à déplacer

effectuer le déplacement

Résolution de mouvement
vérifier les attaques d’opportunité

si le déplacement mène à une capture / attaque, résoudre l’attaque

Résolution d’attaque
calculer dégâts / formes / traversées

appliquer la défense éventuelle

appliquer les dégâts

appliquer les altérations

vérifier les morts

si capture, appliquer le déplacement final sur la case

Après-combat
vérifier :

level-up

promotion éventuelle

déclenchements de kill

cartouches gagnées

effets de roi / reine

Fin de tour
réduire les durées des altérations

vérifier la pression du roi

passer au tour suivant

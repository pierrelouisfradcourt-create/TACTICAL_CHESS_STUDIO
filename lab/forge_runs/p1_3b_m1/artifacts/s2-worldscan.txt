## WORLD SCAN — Tower Defense (Genre)

### Observation Générale

Le Tower Defense présente une boucle coeur structurée autour du **positionnement défensif + économie de ressources + adaptation à l'escalade**. Observé sur trois implémentations canoniques : **Bloons TD 6** (2018–2026), **Plants vs. Zombies** (2009), **Kingdom Rush** (2011). Trois approches distinctes du même problème fondamental : repousser une vague d'ennemis avec une défense construite progressivement.

### Analyse Comparative : Boucles et Rétention

#### 1. **Bloons TD 6** ([Bloons Tower Defense Wiki](https://en.wikipedia.org/wiki/Bloons_TD_6) · [Strategy Guide](https://www.bloonswiki.com/Strategy:Bloons_TD_6) · [Tier List 2026](https://findingdulcinea.com/bloons-tower-defense-6-tier-list/))

**Architecture supposée :**
- Modèle économique : monnaie par destruction (pop bloon = cash) + fermes génératrices (Banana Farm = brique de réinvestissement)
- Système de progression : Triple upgrade paths par tour (path 1, path 2, path 3) + cross-pathing (synergies)
- Meta : Heroes (level 1→20 via XP), Monkey Knowledge (6 arbres d'enhancement)
- Cycles d'escalade : Round 40 = MOAB crunch (point d'inflexion critique)

**Boucles de rétention :**
- **Minute 1** : Place Dart Monkey ou Ninja, observe premiers Bloons en vagues paires (régulières). Économie : collecte cash des bloons tués, gère son premier achat.
- **Minute 10** : Réseau de tours émergeant, stratégie de positionnement pour couvrir plus de track, commence accumulation d'XP et Monkey Money (débloque permanents).
- **Heure 5** : Progression en difficulté Hard = double cash, découverte de heroes (Obyn, Sauda), farming de Monkey Knowledge pour déblocages, adaptation à nouveaux types d'ennemis (Lead, Ceramic, MOAB).
- **Endgame** : Rounds 40+ = défis stratégiques extrêmes, synergies complètes de tours, optimisation des upgrades pour survivre à l'inflation d'ennemi.

**Victoire/Défaite :**
- Mode : Survival standard (vagues infinies jusqu'à défaite)
- Victoire : Pas de victoire assignée (mode marathon) – survive = win
- Défaite : 1 leak au-delà de la fin de la map
- Objectif joueur : Maximiser le round, débloquer meta, collectionner heroes rares

**Pourquoi le joueur revient :**
Meta-progression profonde (6 arbres Monkey Knowledge, heroes XP, tower XP, Monkey Money) + défi à résoudre (comment battre le Round 60?) + collection (completionist: tous les heroes, toutes les upgrades cross-path). Chaque run expose une nouvelle combinaison stratégique.

#### 2. **Plants vs. Zombies** ([Medium: Owen Ketillson](https://medium.com/owen-ketillson/how-plants-vs-zombies-brought-literacy-to-the-tower-defence-71f5c808572b) · [Adventure Mode Wiki](https://plantsvszombies.fandom.com/wiki/Adventure_Mode) · [Game Modes](https://plantsvszombies.wiki.gg/wiki/Game_modes_(PvZ)))

**Architecture supposée :**
- Modèle grille 5×9 (5 lignes, 9 colonnes) : déplacement ennemi = droite→gauche (une dimension seulement)
- Économie : sun-generation (tomb pierre = 25 sun, sunflower = accélère production), achat de plantes
- Progression : 50 niveaux × 5 zones (Day, Night, Pool, Fog, Roof), chaque zone déverrouille une nouvelle plante
- Design d'accessibilité : information non cachée (wave suivante est affichée, ennemis visibles, feedback clair sur l'erreur)
- Variété de jeux : Adventure (50 niveaux) + Puzzle Mode (Vasebreaker, I, Zombie) + Mini-games + Survival Mode

**Boucles de rétention :**
- **Minute 1** : Placer Peashooter, générer sun via Sunflower, comprendre que une ligne = une mini-partie parallèle. Première destruction = feedback immédiat.
- **Minute 10** : Découvrir les contres (Wall-nut vs Zombies costauds, Potatomine vs Poleycat), adapter par lane. Feedback clair sur erreur : « pourquoi j'ai perdu cette ligne? » → réponse évidente (mauvaise plante, mauvais positionnement).
- **Heure 5** : Progression à travers zones (Night = pas de sun naturel, graves, mushrooms; Pool = plantes aquatiques). Déverrouillage constant (1 plante par niveau ~).
- **Endgame** : Survival Mode (vagues infinies post-campagne), mini-games (vasebreaker = puzzle contraint), défis quotidiens (Daily Challenge).

**Victoire/Défaite :**
- Mode Adventure : Chaque niveau = 1 objectif
- Victoire : Tous les zombies d'une wave détruits avant d'atteindre le côté gauche
- Défaite : Tout zombie qui franchit le bord gauche (maison perdue)
- Objectif joueur : Complète les 50 niveaux, débloquer toutes les plantes, maîtriser Survival

**Pourquoi le joueur revient :**
Déblocages constants de plantes (dopamine de collection) + variété de zones (chaque zone = mécaniques nouvelles) + accessibilité (pas de spike inexplicable, feedback juste). PopCap maintient l'engagement via variété de modes (Adventure ≠ Puzzle ≠ Survival ≠ Mini-games) plutôt que de profondeur pure.

#### 3. **Kingdom Rush** ([Jake Pauls Medium](https://jake-pauls.medium.com/towers-towers-everywhere-9a7931a9ed43) · [Kingdom Rush Wiki](https://kingdomrushtd.fandom.com/wiki/Kingdom_Rush) · [Endless Challenge](https://kingdomrushtd.fandom.com/wiki/Endless_Challenge))

**Architecture supposée :**
- Système de tours : 4 types fondamentaux (Barracks/Archer/Mage/Bombard), chacun counters un ennemi-type spécifique
- Progression : Stars par niveau (0/3) → unlock permanent tower upgrades sur un skill tree global (0/130 stars à collecter)
- Escalade : Normal → Heroic (+ difficulté) → Iron (+ difficulté extrême), chacun = 1 star bonus
- Endless Mode : Vagues infinies avec escalade 2% HP/DMG par vague, minibosses toutes les 10 vagues

**Boucles de rétention :**
- **Minute 1** : Placer premières tours (Militia vs Melee, Archer vs Flying), observer ennemi-type spécifique. Économie : placement stratégique = income via kills.
- **Minute 10** : Adaptations aux ennemi-types, synergies de tours (Archer faible en dégâts → combine avec Mage pour AOE). In-game Encyclopedia explique les matchups.
- **Heure 5** : Complétion de niveaux en Normal, puis Heroic, puis Iron (3 run/niveau minimum pour max stars). Progression tangible : 0/130 stars motivent la réplay.
- **Endgame** : Endless Mode + Leaderboards, optimisation stratégique pour round maximal, accumulation de upgrades permanents.

**Victoire/Défaite :**
- Mode : Standard campaign + Endless
- Victoire : Toutes les vagues détruites avant d'atteindre la fin de la map
- Défaite : Perte de 20–40 HP (variable par niveau, Endless = 20)
- Objectif joueur : Collectionner stars (0→130), débloquer towers (nouvelles towers un fois par niveau), vaincre leaderboards

**Pourquoi le joueur revient :**
Star-collection system (completion gratification) + tower unlock progression (chaque niveau = nouvelle tour possible) + difficulty variants (3 plages de difficulté = 3 réplay strategies) + Endless Mode + Leaderboards (compétition sociale). Chaque niveau offre 3 chemins de réplay distincts (Normal→Heroic→Iron = stratégies différentes).

---

### Architecture Candidate à l'Import (Knowledge Base)

1. **Économie progressive** : Bloons (destruction-funded) vs PvZ (natural generation + conversion) → **pattern : génération + puit asynchrone**
2. **Escalade d'ennemi** : Bloons (round-based, type-addition) + Kingdom Rush (wave-based, scaling) → **pattern : crunch point à round 40 (découverte Bloons)**
3. **Collection + Déblocage** : PvZ (50 plantes en 50 niveaux), Kingdom Rush (tower unlocks) → **pattern : 1 unlock/niveau pour dopamine continue**
4. **Skill tree / Meta** : Bloons (Monkey Knowledge 6 arbres), Kingdom Rush (permanent upgrades 0/130) → **pattern : progression hors-session attachée à account**
5. **Variété de modes** : PvZ (Adventure + Puzzle + Mini-games + Survival) → **pattern : antialiasing de la fatigue via mode-switch**
6. **Difficulty scalable** : Kingdom Rush (Normal→Heroic→Iron) → **pattern : même niveau = 3 stratégies émergeantes**

---

### Observable Player Feedback (Advisory)

- **Clarté d'information** : PvZ excelle (wave suivante visible, ennemis affichés) vs Bloons (Round 40 MOAB = spike non-annoncé = frustration possible)
- **Positional diversity** : Tower Defense force le joueur à raisonner en **placement spatial** (Bloons : couvrir le track) vs **lane thinking** (PvZ : 5 jeux parallèles)
- **Feedback loop speed** : PvZ = rapide (1 level ~3 min), Kingdom Rush = modéré (1 level ~5–10 min), Bloons = variable (Round dépend de stratégie)
- **Endgame structure** : Bloons (infinite, no cap), Kingdom Rush (star collection 0/130 = cap), PvZ (Adventure + Survival bifurcation)

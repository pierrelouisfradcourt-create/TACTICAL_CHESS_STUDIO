Ils certifient leurs propres copies inlinées, pas le code chargé par `index.html:175` (`<script src="game.mjs">`). 3 des 4 volets de `run-oracle.mjs` sont découplés de l'artefact expédié ; seul le volet e2e (navigateur) touche réellement `game.mjs`. Une divergence introduite dans `game.mjs` laisserait logic/properties/solvability **verts**.
- **sévérité** : HIGH

## F3 — `SeededRandom` est mort ET arithmétiquement cassé : `next()`/`rand()` renvoient toujours 0
- **angle** : mécanisme déclaré / non exécuté + primitive fausse.
- **faille** : `game.mjs:7-14` — `next()` calcule `this.seed = (…)>>>0` (donc `seed ∈ [0,2^32)`) puis `return (this.seed / 0x100000000) >>> 0`. Or `seed/2^32 ∈ [0,1)`, et `>>> 0` tronque à **0** : `next()` renvoie toujours 0, `rand()` = 0. La classe « Seeded PRNG for deterministic behavior » (`game.mjs:1`) est jamais appelée par une mécanique **et** constante. Tout l'appareil de seed décore une primitive inerte.
- **sévérité** : MEDIUM
- **reproduction** : `assert.strictEqual(new SeededRandom(42).rand(), 0)` (vrai) ; `assert.notStrictEqual(new SeededRandom(1).next(), new SeededRandom(2).next())` → **ÉCHOUE** (0 === 0). Statiquement décidable par l'arithmétique.

## F5 — `isWon()` contredit la règle de victoire à l'état initial ; deux tests verts se contredisent
- **angle** : incohérence logique / cache de victoire non évalué (état initial déjà aligné).

L'état initial `[0,0,0]` satisfait pourtant la règle `s0===s1===s2` (`game.mjs:90-97`). `isWon()` renvoie le cache périmé (`false`), pas l'évaluation vive : statut rapporté ≠ plateau réel. Le puzzle **démarre dans une configuration gagnante** masquée par le cache. Le corpus acte les deux comportements pour le MÊME plateau : `properties.test.mjs:104-116` (Property 2, après `checkWinCondition`) exige `isWon()===true` ; `properties.test.mjs:192-201` (Property 7) et `logic.test.mjs:99` (Test 1) exigent `isWon()===false`. Les deux passent selon qu'on lit avant/après l'éval — oracle auto-contradictoire, vert.
- **sévérité** : MEDIUM
- **reproduction** : `const g=new GameState(); const s=g.getAllCharacterStates(); assert.strictEqual(g.isWon(), s[0]===s[1]&&s[1]===s[2])` → **ÉCHOUE** (`false !== true`).

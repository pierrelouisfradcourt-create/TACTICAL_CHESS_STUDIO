## OBSERVATION ARCHITECTURALE — GENRE CLICKER/INCREMENTAL

### Cookie Clicker — Boucle Active→Passive avec Reset Prestige

**Observation structurelle** : Cookie Clicker perfectionne un design d'économie en cascade où chaque achat libère une automatisation croissante. La mécanique clé n'est pas d'appuyer sur le bouton (cela demeure disponible), mais de **percevoir l'accélération progressive** du taux de production passif. Chaque palier d'achat ouvre un nouveau bâtiment avec ses proprio visuelles, renforçant la sensation d'avancement.

**Architecture des 4 boucles** :
- **Minute 1** : Cliquer sur un gros cookie. Feedback immédiat (1 cookie, animation d'éclatement du cookie, éclaboussures). Son: clic satisfaisant. Objectif instantané : acheter 1er curseur (13 cookies).
- **Minute 10** : 1er curseur automatise à 0.1 cookies/sec. Joueur voit la production sans action. Golden Cookie peut apparaître (effet aléatoire temporel). Le vrai drive : comparer coût(curseur 2) vs coût(1ère ferme) ; attendre ou cliquer ? → Décision économique minimale.
- **Heure 5** : 15+ bâtiments existants. Production passive dominante (>90% des revenus). Sugar Lumps arrivent (resource rare, 24h pour s'accumuler). Wrinklers aparaissent (récompense du clic qualitatif = pop le wrinkler). **Pourquoi revient-on** : chaque session ouvre une nouvelle branche d'upgrade, la progression n'est JAMAIS gelée, et la gestion des Wrinklers demande 1 click tous les 2-3h.
- **Endgame (>100h)** : Ascension = reset volontaire pour accumuler Heavenly Chips (prestige). Chaque ascension multiplie la production initiale (prestige = +1% CPS par niveau). 637 achievements palpent l'espace. Krumblor (dragon) déverrouille puis se dresse, révélant une mini-game de pêche. **Pourquoi revient-on** : l'ascension est addictive (une source illimitée d'upgrades ; chaque ascension court est stratégiquement différente), et les minigames offrent une mécanique différente (sugar lumps, lotteries).

**Conventions visuelles** : Lait du cookie (% achievements) colore le bg de blanc→gris→noir progressif. Grandmapocalypse assombrit l'écran et transforme les éléments UI (horror narrative). Particules de nombre flottant lors d'un achat. Number formatting scalable (1K, 1M, 1B…) rend la croissance exponentielle lisible.

**Conventions sonores** : Clic sec per click. Son doux (chime) quand Golden Cookie apparaît. Son distinct (pop) pour Wrinkler. Ascension = jingle épique de réinitialisation.

**Absence de défaite** : Pas de gameover, pas d'échec. Le coût d'une mauvaise décision d'upgrade est un délai de progression, pas une pénalité.

### Neko Atsume — Collection Passive avec Time-Gate Soft

**Observation structurelle** : Neko Atsume inverse le paradigme : au lieu de **multiplier un nombre**, on **attrape des créatures**. L'économie est linéaire (chat laisse X poissons ; poissons → acheter décor/nourriture → attirer un nouveau chat). Le design repos sur **la découverte** : chaque chat est rare jusqu'à sa première visite.

**Architecture des 4 boucles** :
- **Minute 1** : Ouverture : cour vide, 5000 poissons d'démarrage. Acheter 1 bol de nourriture basique. Son : 1 ting mou par achat. **Pourquoi revenir** : voir si un chat arrive tout seul (pas urgent).
- **Minute 10** : 1er chat arrive. Feedback visuel = animation d'arrivée, interactif (tap pour prendre une photo memenento). Chat repart après 20-60 min, laisse 10-100 poissons. **Pourquoi revenir** : curiosité sur le **prochain** chat ; changer la nourriture pour en attirer un différent.
- **Heure 5** : Joueur a vu 10-15 chats distincts. Rare cats (combinaisons spécifiques de décors/nourriture) commencent à devenir visibles comme des objectifs. Photo mementos s'accumulent (Pokedex parallèle). Time-gated password quotidien = +500-2000 poissons aléa. **Pourquoi revenir** : collectionnisme ; password quotidien ; expérimentation de combos.
- **Endgame (>50h)** : 86 chats, 26 rares. Seasonal events (neige = chats exclusifs hiver). Mementos : 250+ possibles. À ce stade, la collection est l'**unique drive**. Pas de prestige, pas d'ascension. **Pourquoi revient-on** : complétionisme dur de la collection + events saisonniers avec exclusivité temporelle.

**Conventions visuelles** : Illustration 2D kawaii des chats (chacun avec traits distinctifs). Particules de pièces flottant quand un chat laisse un reward. Indicateur simple du nombre de chats uniques vus / total (ex: 43/86). Pas d'animation de production (contrairement à Cookie Clicker) : c'est l'**arrivée du chat** qui est l'événement.

**Conventions sonores** : Ronronnement des chats quand ils mangent. Tink léger = pièce gagnée. Jingle distinct = rare cat découvert. Pas de musique alarme ou dramatique : atmosphère zen (même si le jeu est addictif).

**Absence de défaite** : Aucun risque d'échouer. Si tu ne places pas de nourriture, les chats cessent de venir (timeout silencieux), mais il n'y a **pas de "jeu over"** — on peut toujours replacer la nourriture et recommencer.

---

### Risques du Genre & Mitigations Observées

**Monotonie** : Les deux jeux risquent de devenir répétitifs (clic vide, attendre).
- **Cookie Clicker mitigue par** : Minigames (sugar lumps, Krumblor, Grandmapocalypse narrative), ascensions qui changent la stratégie.
- **Neko Atsume mitigue par** : Variété des chats (86 designs uniques), seasonal events, mementos photo (collectionnisme narratif).

**Fatigue des clics constants** (Cookie Clicker surtout) :
- Mitigation : Bâtiments automatisent progressivement ; clicker devient optionnel dès minute 15.

**Absence d'échec** :
- Peut réduire le **stake** du jeu. Les deux jeux le compensent par un **objectif clair implicite** : Cookie Clicker → "How big can my number go?" ; Neko Atsume → "Collect them all".

## OBSERVATION MONDE — CLICKER/IDLE INCREMENTAL

### Cookie Clicker: Archétype de l'escalade exponentielle

**Core Loop**: clic → cookies → achat de bâtiments → automation croissante → prestige/ascension

**4 Horizons de Progression:**

1. **Minute 1** : Le joueur découvre le clic immédiat. Premiers coups de souris sur le cookie géant. Feedback instantané (nombre qui monte). Premier achat (~13 cookies pour un curseur) = sensibilité du coût élevé. Mécanisme de DÉCOUVERTE du prix.

2. **Minute 10** : 5–10 bâtiments achetés (cursors, grandmas, farms). Automation commence : les compteurs montent même pendant l'inactivité. Le joueur constate que "laisser tourner" **produit plus** que de cliquer. Psychologie clé : **renoncer au clic pour l'automation rapporte davantage**. Introduction des upgrades (multiplicateurs 2× ou 10× pour un bâtiment).

3. **Heure 5** : Économie complexe (20+ bâtiments). Apparition des **golden cookies** = variance tactique dans l'automation (cliquer au bon moment = +0 secondes de gain). Wrinklers = parasites qui ralentissent la prod, mais "pop" = intérêt exponentiel. Sugar Lumps = progression long-terme (leveler les bâtiments). Achievements = collatéral (27 golden cookies cliqués = débloquer une upgrade). Le joueur gère QUAND dépenser (attendre prestige? acheter ce nouveau bâtiment? lever les buildings?).

4. **Endgame (plusieurs semaines)** : Ascension = reset complet MAIS garde prestige (+1% CpS par level). Le joueur vise des achievements "all time" (7777 golden cookies cliqués) et **rejoue entièrement** pour gagner prestige plus vite. Boucle meta : run → ascend → run faster. Pas de fin déclarée.

**Réponse : Pourquoi le joueur revient?**
- Dopamine du nombre qui monte (feedback auditif + visuel constant)
- Sensation de progression même inactif (passive income = victoire même en dormant)
- Micro-décisions (ascend now vs. wait pour plus prestige?)
- Achievements = tâches cachées qui allongent la durée de vie

**Conventions Visuelles/Sonores du Genre:**
- Son **crunch** à chaque clic (gratification auditive)
- Nombre volant vers le haut en cas de gain large
- Animation de bâtiments qui "travaillent" (cheminées qui fument, grandmas qui cuisent)
- Background qui se remplit (plus tu progresses, plus le décor est riche) — exemple : Cookie Clicker passe d'une cuisine de base à une usine cosmique

**Risques de Monotonie:**
- Après 20 heures : le clic est déjà mort (inutile de cliquer si les bâtiments font tout)
- Progression devient **algébrique, pas organique** — pas de new story, juste des chiffres qui montent
- Wrinklers et golden cookies = **seuls éléments d'incertitude tactique** — si on les enlève, c'est répétition pure

### Neko Atsume: Archétype de la collection asynchrone

**Core Loop**: placer jouets/nourriture → fermer l'app → chats visitent pendant l'absence → collecter fish → acheter nouveaux jouets

**4 Horizons de Progression:**

1. **Minute 1** : Le joueur ouvre l'app, découvre la cour vide (yard). Achète son premier jouet (ex. blue cushion, ~20 fish) avec le starting fish. Place le jouet. **Nul n'apparaît immédiatement** — première leçon clé : "il faut partir pour que les chats viennent". Sensation de maîtrise inversée (je dois ignorer le jeu pour y progresser).

2. **Minute 10** : Joueur ferme l'app, la rouvre après 1–2 minutes. 2–3 chats uncommon ont visité, laissé 50–100 fish. Dopamine du *return-to-app*. Joueur regarde les photos, lit les noms. Cycle répété : "place new toy → go away → check → new photo → joy".

3. **Heure 5** : 5–15 jouets accumulés. Progression vers les **rare cats** = quête explicite dans le Catbook. Neko Atsume divulgue les préférences : "Conductor Whiskers aime la railway, la nourriture bombe, et l'eau froide". Joueur économise pour acheter ces 3 objets (~500+ fish total). Sensation de **quête cachée** (Catbook = progression tracker).

4. **Endgame (plusieurs mois)** : 27 rare cats collectés, Catbook 100% rempli. Chaque rare cat laisse un **memento unique** (photo signée, shuriken papier). Pas de nouveau contenu après 100%, mais la beauté des collections = reward. Joueur peut passer au NG+ cosmétique (thèmes de cour, nouvelles saisons).

**Réponse : Pourquoi le joueur revient?**
- FOMO faible (les chats ne disparaissent jamais, juste moins souvent)
- Quête de collection = objectif clair et mesurable
- Chaque nouvelle rare cat = sentiment d'accomplissement unilatéral (pas de fail state)
- Asynchrone = zéro addiction aiguë (pas de push notifications stressantes, pas de "dépêche-toi!")

**Conventions Visuelles/Sonores du Genre:**
- **Silence auditif complet** — Neko Atsume est muet sauf pour un *boing* discret quand un chat apparaît
- Photos HD des chats en poses dorées (chibi-style) = collection pokémon
- UI minimaliste : yard, shop (1 onglet), Catbook (1 onglet) — pas de inflation de menus
- Progression visuellement claire : yard vide → yard rempli de 15 jouets → décor cohérent

**Risques de Monotonie:**
- Gameplay très limité (placer jouet = seule action du joueur)
- Pas de défi (aucun fail state, juste "attendre que la cat rare vienne")
- Après 100% Catbook : **rien ne change**. Zéro gameplay nouveau, même après 1 an
- Gestion de l'absence : joueur peut oublier l'app pendant 3 mois, rouvrir, trouver les chats toujours là — déconnexion émotionnelle possible

### Archétype Genre: Patterns Communs

| Axe | Cookie Clicker | Neko Atsume |
|-----|---|---|
| **Unité d'action** | Clic (interactif) | Placement + attente (passif) |
| **Monnaie** | Cookies (numérique) | Fish (cosmétique) |
| **Win State** | None (indefinite) | Catbook 100% (achievable, long) |
| **Feedback Loop** | <1s (number goes up) | Async (return-to-app) |
| **Pacing** | Urgence d'achat (escalade) | Zen (pas d'urgence) |
| **Retention Lever** | Prestige/meta-loop | Rarity/collection |
| **Monotony Risk** | Math becomes transparent | Gameplay becomes passive |

## ADVISORY: Conventions VISUELLES DU GENRE CLICKER

D'après les sources Mind Studios (2025) et Wikipedia :

- **Progress Bar** : numéro principal doit être **lisible du coin de l'œil** — Cookie Clicker utilise 64px+ pour le compteur de cookies
- **Cascade Visuelle** : chaque achat = animation de chaîne (curseur animate → grandma animate → farm animate), renforçant la sensation d'une vraie machine
- **Sondes d'Information** : Neko Atsume émeut via **rareté de la photo** (rare cat = HD chibi cute) ; Cookie Clicker émeut via **bruit de succès** (cash register sound sur un gros achat)
- **Absence de Punition** : ni Cookie Clicker ni Neko Atsume n'ont de game-over. Les deux priorisent **reposing, not punishing**.

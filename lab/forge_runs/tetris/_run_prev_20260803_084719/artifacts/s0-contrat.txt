Conséquence directe, déjà pressentie dans `game_contract.yaml` : **la solvabilité ne peut PAS être « un bot gagne »** — elle se définit comme « un bot **survit** N pièces **et** nettoie ≥1 ligne sans blocage prématuré ».

### 2 — `hors_scope[]`

### 3 — `criteres_succes[]` (objectifs, oracle-ables — non-LLM)
1. **Sac de 7** : le générateur émet exactement {I,O,T,S,Z,J,L}, chacune une fois par sac de 7, aucune autre forme.
2. **Gravité discrète** : sans input, la pièce active descend d'**exactement 1 case** par tick de gravité.
3. **Empilement irréversible** : une pièce figée est immuable — aucun input ne la déplace/retire (assert état inchangé).
4. **Nettoyage + compactage STRICT** : une rangée pleine disparaît et tout ce qui est au-dessus descend d'**exactement** le nombre de rangées nettoyées — assertion **stricte**, jamais `>=` (pré-mortem : pas de `>=` tautologique).
5. **Rotation contrainte** : une rotation qui collisionne est **refusée**, la pièce garde son orientation/position, le terrain n'est jamais déformé.
6. **Input sur pièce active seule** : translation/rotation/soft-drop n'affectent que la pièce active, jamais la pile.
7. **Fin par blocage** : quand une pièce entrante ne peut pas apparaître légalement, l'état devient terminal (game-over).
8. **Solvabilité honnête** (obligatoire s9) : un bot scripté survit ≥ N pièces **et** nettoie ≥1 ligne sans game-over prématuré — N à calibrer (solvability = `A_CALIBRER` dans `game_contract.yaml`). Pas « un bot gagne ».
9. **Livrable Godot** : le projet se lance (fenêtre GPU, cf. contrainte capture) et une partie complète se joue jusqu'au game-over sans crash.

# Progression Map

Tetris Guideline: Level-based progression (fixed line counts), Gravity multiplies exponentially early then logarithmically. Retention via high-score chasing, skill thresholds (level advancement=mastery), leaderboards. Sources: https://tetris.wiki/Tetris_Guideline

NES Tetris: Fixed 10-line level threshold, Gravity increases per level, Max at level 29 (impossible). Retention via score progression per level, difficulty ladder, retro appeal, tool-assisted speedruns. Sources: https://howtotetris.com/classic-tetris/

Puyo Puyo: Chain depth as progression vector (1-5 exponential, 6+ linear). No gravity acceleration; difficulty=chain complexity. Retention via chain mastery, competitive vs mode tension, pattern recognition. Sources: https://puyonexus.com/wiki/Puyo_Puyo

V1 Recommendation: Line accumulation (primary), gravity step-down per N lines (constant gravity V1), personal best line count=motivation. No superlinear score multipliers (FOG-3 deferred). No leaderboard V1.

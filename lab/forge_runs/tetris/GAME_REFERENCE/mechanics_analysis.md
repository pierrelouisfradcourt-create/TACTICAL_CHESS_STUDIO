# Mechanics Analysis

## Games Analyzed
- Tetris Guideline (2001–present): https://tetris.wiki/Tetris_Guideline, https://harddrop.com/wiki/SRS, https://tetris.fandom.com/wiki/Tetris_Guideline
- NES Tetris (1989): https://famiwiki.net/wiki/Tetris_(NES), https://howtotetris.com/classic-tetris/, http://www.world-of-nintendo.com/manuals/nes/tetris.shtml
- Puyo Puyo (1992–present): https://puyonexus.com/wiki/Puyo_Puyo, https://puyonexus.com/wiki/Special_Maneuvers_and_Mechanics, https://puyonexus.com/forum/viewtopic.php?f=40&t=2304

## Key Mechanics Compared

Tetris Guideline: 10x20 grid, 7 tetrominoes, Bag randomizer, SRS rotation with wall-kick, Gravity decoupled, Lock delay.
NES Tetris: 10x20 grid, 7 tetrominoes (probability-weighted), No wall-kick, No lock delay, DAS input constraint.
Puyo Puyo: 6x12 grid, Color pairs, Match 4+ (not line-clear), Cascade chains, Constant gravity.

## Patterns for V1

Recommended: 10x20 playfield, Bag randomizer, Collision-refusal rotation, 1 piece preview, Soft-drop included, No hard-drop, Independent gravity tick, Constant gravity V1.

# SECTION 4 - — HISTORIQUE DES TESTS, BANS ET ABUS
4.1 Contrôle fort
Gel
Abus : trop fort sur zone, sur ligne longue, sur tour

Pourquoi : gèle des lignes entières, rend certaines positions impossibles à jouer

Réponse : très rare, surtout sur fou, interdit avec certaines géométries

Statut : limité / rare

Racines
Abus : très fort sur cavalier ou en grande zone

Réponse : recentré vers le fou ; rare sur autres pièces

Statut : limité

Désarmé
Abus : détruit le jeu si combiné avec ligne/portée

Réponse : très rare, fortement taxé, surtout sur fou

Statut : limité / quasi interdit hors fou rare

Peur
Abus : peut faire reculer un roi et supprimer une défense

Réponse : classée comme grosse altération rare, proche du stun en rareté

Statut : rare

Charme
Abus : peut être extraordinairement toxique si large zone

Réponse : très rare / très surveillé

Statut : encore en test / hautement surveillé

Confusion
Abus : forte perturbation mentale

Réponse : intéressante mais pas figée

Statut : encore en test

Stun
Abus : trop violent

Réponse : envisagé comme ultra rare, presque bannière rouge

Statut : toléré uniquement très rare / presque banni

4.2 Portée
Portée longue + effet
Abus : sniper/contrôle trop sûr

Réponse : taxe de portée appliquée aussi aux effets

Statut : limité

Cavalier portée native
Abus : casse son identité et le rend toxique

Réponse : refus de portée étendue native ; seulement cartouches limitées chez Pirates

Statut : interdit hors exception

4.3 Ligne complète
Abus : rend les tours / reines oppressives

Réponse : très forte taxe, rareté extrême, parfois interdite avec effets

Statut : rare / très surveillée

4.4 Zone
Abus : zone + effet fort

Réponse : taxe lourde, réduction de dégâts, interdits ciblés

Statut : tolérée avec garde-fous

4.5 Poison
Abus : faisait trop de choses à la fois

Réponse :

non cumulatif

pression réduite

Statut : toléré / stabilisé

4.6 Cavalier
Abus :

opening trop fort

contrôle trop fort

trop d’early pressure

Réponse :

baisse de PV

rôle protecteur / escarmouche

pas de contrôle fort

Statut : recentré

4.7 Reine
Abus : trop polyvalente

Réponse : offensive quasi pure

Statut : recentrée

4.8 Tour
Abus :

portée excessive

ligne complète

debuff fort

Réponse :

taxe universelle

perte de PV/ATK si ligne longue

tour + gel considéré comme mauvais

Statut : fortement surveillée

4.9 Fusions
Abus :

gratuites

trop tanky

roque

Réponse :

certains coûts en sort

roque interdit

dégâts d’une source appliqués une seule fois

Statut : tolérées avec garde-fous

4.10 Sorts globaux
Abus : trop de support global ou de contrôle global ralentit ou casse le jeu

Réponse : effets globaux modestes

Statut : limités

4.11 Invocations
Abus : spam de board

Réponse :

1 invocation permanente max

exception possible pour la couvée

Statut : limité

4.12 Résurrection
Abus : peut casser l’attrition

Réponse : résurrection à 1 PV, rare, pas figée

Statut : encore en test

4.13 Sideboard
Abus : side trop puissant peut rendre certaines stratégies trop flexibles

Réponse : 1 sort/tour, coûts de fusion, usages encadrés

Statut : toléré / central

4.14 Pression du roi
Abus : double peine avec certains debuffs

Réponse : recalibrage, poison nerfé

Statut : stabilisé mais à prototyper

# SECTION 3 - — Missing Systems
These are systems that would substantially improve the encyclopedia if added formally.

1. Explicit content-generation legality matrix
The encyclopedia defines the philosophy of generation, but not a formal legality matrix such as:

which piece types may roll which status tiers

which geometries may coexist with which status tiers

which traversal modes are legal per piece class

which combinations are legal by rarity

This is one of the most important missing systems.

2. Rarity framework
The encyclopedia does not yet define:

full rarity distribution

power budget deltas by rarity

complexity budget by rarity

how rarity affects procedural generation weights

This is essential for a franchise model.

3. Terrain system
Board, tile, and traversal exist, but a terrain framework is not specified.

Needed:

terrain tags

blocking types

hazard timing

duration for temporary terrain

interaction with line of sight and traversal damage

4. Promotion system
The encyclopedia names pieces and pressure but does not formalize:

promotion trigger

promoted piece sourcing

whether promotion uses procedural pools

whether promotion preserves statuses

whether promotion is faction-bound

This is a major missing system.

5. Draft and sideboard framework
The project identity mentions procedural generation and tactics, but draft architecture is not yet specified in the encyclopedia.

Needed:

draft flow

pool generation

sideboard rules

whether sideboard pieces can be summoned

interaction with procedural cards

6. Fusion / combination framework
Given the project’s direction, this is likely highly relevant but absent from the encyclopedia.

Needed:

legal fusion pairs

timing

size rules

stat recomputation

status inheritance

anti-abuse constraints

7. Range and geometry taxonomy
Right now the encyclopedia gives formulas, not a full attack taxonomy.

Needed:

geometry list

targeting rules

visibility rules

stop rules

traversal interaction

8. AI evaluator model
The simulation lab exists, but there is no explicit board evaluator or heuristic model.

Needed:

positional score

king safety score

pressure score

lane control score

tempo score

entropy penalty

readability / complexity score for generated cards

9. Set-level balancing constraints
For procedural design, balancing individual cards is not enough. Missing:

per-set status density caps

range-density caps

summon-density caps

faction overlap caps

opening diversity targets

10. Canonical keyword list
The encyclopedia would greatly benefit from a formal keyword vocabulary:

Burn

Poison

Root

Disarm

Fear

Charm

Piercing

Splash

Traversal

Pressure

etc.

This is crucial for scale.

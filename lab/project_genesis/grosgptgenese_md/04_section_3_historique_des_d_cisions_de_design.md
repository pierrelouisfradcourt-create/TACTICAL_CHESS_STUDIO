# SECTION 3 - — HISTORIQUE DES DÉCISIONS DE DESIGN
3.1 Point de départ : “échecs enrichis”
Le projet est parti d’un désir de transformer les échecs en un système plus riche :

figurines

cartes

factions

draft.

Problème initial
Comment enrichir les échecs sans en détruire l’identité ?

Solution retenue
Préserver :

l’échiquier

les déplacements

les rôles des pièces

et enrichir par :

attaques

effets

set-building.

3.2 Tournant “franchise”
Très tôt, le projet a glissé d’un simple jeu vers une logique de franchise.

Problème
Un jeu de plateau avec juste quelques variantes s’épuise vite.

Options
peu de factions simples

beaucoup de factions

sets successifs

Solution
Concevoir le système comme :

franchise physique + numérique

factions modulaires

extensible à long terme.

3.3 Tournant “factions et heroes packs”
Le système a ensuite basculé vers des micro-sets de héros.

Problème
Le draft pouvait manquer de cohérence ; certaines combinaisons de pièces n’avaient pas d’âme.

Options
draft pièce par pièce

set de base neutre

micro-sets héros

Solution
Associer à chaque héros un noyau de pièces liées :

roi

reine

backline

pions spéciaux.

Cela a énormément renforcé :

la lisibilité

la vente en set

la cohérence de faction.

3.4 Tournant “RNG contrôlée”
Le créateur a insisté pour ne pas perdre la RNG, tout en la contrôlant fortement.

Problème
Une RNG trop libre casse le jeu.

Options
stats fixes

quelques variations

génération procédurale par budget

Solution
Mettre en place :

budget de puissance

tables de coût

filtres anti-abus.

3.5 Tournant “rôles des pièces”
Le système a progressivement clarifié les rôles :

pion = progression

cavalier = escarmouche / protection

fou = contrôle / support

tour = projection

reine = offensive

roi = moteur stratégique

Problème
Certaines pièces commençaient à tout faire.

Solution
Spécialiser fortement les responsabilités tactiques.

3.6 Tournant “reines offensives”
Le créateur a explicitement demandé de retirer progressivement le rôle support des reines.

Problème
La reine devenait trop polyvalente.

Solution
La considérer comme :

“tueur de l’armée”

offensive avant tout

avec éventuellement au plus 1 reine support pour 3 héros, et encore, plutôt déconseillée.

3.7 Tournant “fou = contrôle”
Le fou est devenu la pièce centrale du contrôle lourd.

Problème
Le contrôle sur cavalier ou tour devenait souvent toxique.

Solution
Déplacer :

gel

racines

désarmé

peur rare

principalement vers le fou.

3.8 Tournant “sideboard actif”
Le sideboard n’était pas central au début.

Problème
Le draft risquait de perdre de sa profondeur après le placement initial.

Solution
Faire du sideboard une ressource active pour :

sorts

promotions

invocations

fusions.

3.9 Tournant “plateau révélé avant la draft”
Problème
La draft était moins stratégique si le plateau était neutre ou inconnu.

Solution
Révéler le plateau avant la draft pour que les picks aient un vrai contexte.

3.10 Tournant “rois ne peuvent pas se toucher”
Problème
Le système risquait de perdre l’âme échecs en endgame.

Solution
Réintroduire explicitement la règle des rois non adjacents.

# Run Contracts

PR-02 defines the immutable run bundle contract for future TacticalChessPureLab Research OS V9.2 runs.

Expected PR-02 verdict:

```txt
software_verdict: NOT_RUN
evidence_verdict: CONTRACT_ONLY
claim_verdict: NO_CLAIM_ALLOWED
```

Core rule:

```txt
PR-02 defines a contract for future immutable run bundles.
It does not create scientific evidence.
It does not authorize claims.
```

This directory contains schemas, rules, and contract-only examples. It does not contain real runs, benchmark outputs, holdout access, runtime behavior changes, or scientific claims.

Examples must stay in `lab/run_contracts/example_run_bundle_contract_only/` and must never be placed in `lab/runs/`.

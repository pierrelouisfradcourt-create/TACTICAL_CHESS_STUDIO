# STATUS_LEGEND

status: DOCUMENTED_ONLY

Allowed status tags:

- IMPLEMENTED: file, folder, code, or documented surface exists in the expected place.
- TESTED: a scoped verification was run and passed.
- DOCUMENTED_ONLY: planning or routing document only; no runtime authority.
- PASSIVE: archive, report, observation, or helper surface; not active proof.
- BLOCKED: must not proceed without explicit HumanGate authorization.
- NOT_FOUND: expected surface not present.
- UNKNOWN: not inspected or insufficient evidence.

Default claim_verdict: NO_CLAIM_ALLOWED.

## Verdict Fields

| verdict | purpose | default |
|---|---|---|
| software_verdict | What the software state supports. | UNKNOWN |
| evidence_verdict | What the available evidence supports. | UNKNOWN |
| claim_verdict | What public or project claim is allowed. | NO_CLAIM_ALLOWED |

Default claim_verdict: NO_CLAIM_ALLOWED

## Claim Restrictions

A benchmark or performance run alone cannot prove:

- Elo
- strength
- scientific validity
- production readiness
- Chess960 readiness
- training readiness
- dataset quality
- model quality
- security
- RGPD compliance

Claims require HumanGate and the appropriate evidence package for the specific scope.

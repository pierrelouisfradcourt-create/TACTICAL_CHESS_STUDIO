## Vision

The studio is a living ecosystem. `C:/TACTICAL_CHESS_STUDIO` is the full Studio ecosystem root and base map.
The central map is now a static inline SVG isometric cartographic city-ecosystem scene rather than tilted dashboard cards because the operator needs vertical authority, rooted foundations, district size differences, paths, blocked territory, and living relationships, not a grid of equal admin panels.

`Studio Core / Root Substrate` is the visible `Foundation Layer`. It represents the base plate of code, docs, tests, artifacts, runtime boundaries, and machine signals.
`HumanGate` is the apex, top summit, and `Final Authority Apex`; it remains the sovereign gardener and final authority.
The zone towers use hardcoded illustrative sample weights only. Tower height and district size do not come from filesystem measurement, repo scanning, runtime telemetry, or any live adapter.

`TacticalChessPureLab — recovered studio organism` is a recovered studio organism district inside the ecosystem, not ecosystem root. ## SVG Isometric Map Rationale

- The central scene is generated as local inline SVG markup from hardcoded sample data in `app.js`.
- SVG polygons create the isometric city plan: foundation platform, tower tops, side faces, shadows, labels, arrows, and blocked territory.
- HumanGate is placed at the top as the summit and Final Authority Apex.
- Studio Core / Root Substrate is placed below every tower as the broad Foundation Layer.
- Major zones are shown as towers, buildings, blocks, and districts with top faces, side faces, and shadows.
- Building height is based only on hardcoded sample weights such as tiny, small, medium, large, and massive.
- Directional SVG paths explain static example flows from core to organism, organism to evidence, evidence to HumanGate, memory to nursery, scout layer to nursery, and climate to HumanGate.
- Toxic / Forbidden Growth is isolated from normal allowed flow with a red blocked SVG line and quarantine border.
